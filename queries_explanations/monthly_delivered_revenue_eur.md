# Monthly Delivered Revenue (EUR)

## Purpose
This query calculates the monthly revenue generated by delivered orders, converted into euros.

## Step 1 – Identify Delivered Orders
The `Order_delivered` CTE joins the `items` table with the `orde_status` table and keeps only orders with the status `04_delivered`.

## Step 2 – Add Order Metadata
The `FullInfo_Order_delivered` CTE joins delivered orders with the `orders` table to retrieve additional information such as:
- country
- currency

## Step 3 – Currency Conversion
The `FullInfo_Order_delivered_withCurrency` CTE joins the dataset with the `currency` table to retrieve the appropriate exchange rate (`eur_value`).

Important details:
- Currency code inconsistencies (`GPB` vs `GBP`) are corrected using a `CASE` statement.
- The exchange rate is selected based on the most recent rate available before the order's `event_date`.
- `ROW_NUMBER()` is used to select the correct exchange rate per order and product.

## Step 4 – Select the Correct Exchange Rate
The `final_step` CTE keeps only the latest valid exchange rate (`row_n = 1`) for each `(order_id, product_id)` pair.

## Step 5 – Revenue Aggregation
The final query:
- extracts the year and month from `event_date`
- converts the item amount into euros (`amount * eur_value`)
- aggregates revenue per month.

## Notes
During validation, several checks were performed to ensure that no NULL values were present in the intermediate datasets.
